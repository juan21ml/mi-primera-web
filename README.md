## 🚀 Cómo Ejecutar Localmente

1. Clona este repositorio:
   ```bash
   git clone https://github.com/tu-usuario/hoja-de-vida-web.git
   cd hoja-de-vida-web
   ```

2. Abre el archivo `index.html` en tu navegador, o usa un servidor local:
   ```bash
   # Con Python 3
   python -m http.server 8000
   
   # Con Python 2
   python -m SimpleHTTPServer 8000
   
   # Con Node.js
   npx http-server
   
   # Con npm (si tienes live-server instalado)
   live-server
   ```

3. Accede a `http://localhost:8000` en tu navegador

## 🌐 Despliegue en Vercel

Esta página está desplegada automáticamente en Vercel y se actualiza con cada push a la rama principal.

### URL Final
**[https://tu-proyecto.vercel.app](https://tu-proyecto.vercel.app)**

### Pasos para desplegar en Vercel:

1. Sube tu código a un repositorio público en GitHub
2. Ve a [vercel.com](https://vercel.com) e inicia sesión con tu cuenta de GitHub
3. Click en **"New Project"** / **"Add New..."**
4. Selecciona tu repositorio
5. Vercel detectará automáticamente la estructura (HTML estático)
6. Click en **"Deploy"**
7. ¡Tu sitio estará en vivo en segundos! 🚀

### Configuración Automática
- No requiere build
- No requiere dependencias
- Deploy automático en cada push a main
